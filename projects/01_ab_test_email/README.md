# A/B тест: влияние email-рассылки на конверсию и ARPU
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kroshko/data-analytics-portfolio/projects/01_ab_test_email/01_ab_test_email.ipynb)

## Задача

Проверить, увеличивает ли промо-рассылка конверсию в покупку и среднюю выручку на пользователя (ARPU) по сравнению с контрольной группой.

## Гипотезы

**H₀:** email-рассылка не влияет на конверсию и ARPU  
**H₁:** email-рассылка увеличивает конверсию и ARPU

## Параметры теста

| Параметр | Значение |
|----------|----------|
| Конверсия (control) | 10% |
| Конверсия (experiment) | 12% |
| Уровень значимости α | 0.05 |
| Статистическая мощность | 0.80 |
| Размер каждой группы | 3 850 (рассчитан аналитически) |

Размер выборки не взят произвольно — рассчитан через формулу для сравнения двух пропорций с учётом заданной мощности и уровня значимости.

## Методы

- **Z-тест** (`proportions_ztest`) — сравнение конверсий (пропорции)
- **T-тест** (`ttest_ind`) — сравнение ARPU (непрерывная переменная)
- Выручка смоделирована через экспоненциальное распределение — соответствует реальной структуре e-commerce

## Результаты

| Метрика | Control | Experiment | p-value | Вывод |
|---------|---------|------------|---------|-------|
| Конверсия | ~10% | ~12% | < 0.05 | Значимо |
| ARPU | ~120 ₽ | ~135 ₽ | < 0.05 | Значимо |

Email-рассылка показала статистически значимый рост обоих показателей. Рекомендация — внедрять.
